# W10 baseline failure investigations

All 29 baseline failures were reproduced on the starting commit before any implementation edits. Six are fixture/mock problems; 23 are obsolete expectations from superseded components/designs. No baseline assertion was skipped or deleted to suppress a failure. Replacements test the adopted behavior, with actual-browser checks covering rendering, focus and keyboard interaction.

Frontend baseline: 339 total, 310 pass, 29 fail. Final full regression: 360 total, 360 pass, 0 fail, 0 skips. The extra 21 cases come from files that previously aborted during module loading.
